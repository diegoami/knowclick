# Knowclick — Roadmap

Technical knowledge by memory and by practice, in the order the owner wants to learn it:
Kubernetes (CKAD, CKA), cloud certifications (Azure first, then AWS and Google Cloud),
languages (Rust, PowerShell, advanced Python), libraries (Neo4j, Kafka, LangChain), and
whatever else needs exercising. Audience size is not a goal.

## Status

**v0.1.0 is in progress** ([proposal #1](https://github.com/diegoami/knowclick/issues/1),
agreed): the Kubernetes pack with three boards and six tasks.

## Milestones

| Milestone | Delivers                                                                                           |
| --------- | -------------------------------------------------------------------------------------------------- |
| v0.1.0    | Kubernetes (CKAD): a table, a manifest and a lines board, six hands-on tasks, Review, verification |
| v0.2.0    | Azure (AZ-900), a second pack to prove packs are pluggable; typed answers (`produce`)              |
| v0.3.0    | CKA coverage in the Kubernetes pack, more CKAD content, a coverage screen                          |
| v0.4.0    | Separate downloads: a packs repository, a catalog, a Library screen                                |
| v0.5.0    | Languages: Rust, PowerShell, advanced Python, with snippets verified by compiler or interpreter    |
| v0.6.0    | AWS and Google Cloud, explained against Azure (comparison overlays)                                |
| v0.7.0    | Libraries: Neo4j, Kafka, LangChain                                                                 |
| Later     | Windows and Android builds; anything else the owner wants to learn                                 |

A later milestone gets its scope settled in its own proposal.
